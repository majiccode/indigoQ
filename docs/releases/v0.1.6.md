# indigoQ v0.1.6 — one canvas for your ideas

Connect documents, data, local AI, and creative tools in a free, open-source
workbench that runs on your computer.

**Try this first: listen to a PDF.** Connect **FileWorkspace → Document Preview →
Text to Speech**, select a PDF with extractable text, choose a voice, and click
**Speak it all**. No Ollama model is required.

## Highlights

- **Creative Workshop:** a ready-wired starter canvas with six new tools, sample
  model/scene data, a mood dashboard, and connected file exports.
- **Electronic Workshop:** component editing, pin wiring, rotation/deletion,
  basic connectivity checks, circuit JSON, and text planning packages.
- **3D Modeler + World Builder:** perspective, solid/wireframe views, culling,
  explicit spin, reusable meshes, instance transforms, and scenes with geometry.
- **ASCII Art:** image-to-ASCII/Braille conversion, table sparklines, and published
  text/TXT files.
- **Ambient Mood:** keyword/table-derived controls, manual/auto mode, and a
  dashboard-friendly output snapshot.
- **USB Debug:** browser-approved devices, interface/alternate selection,
  endpoint reads/writes, hex validation, and published traffic logs.
- Improved Image Studio, speech workflows, documentation, and public guides.

Circuit checks are connectivity heuristics, not an electrical simulation;
planning packages are not fabrication-ready Gerber/drill files. USB Debug
requires WebUSB in a compatible browser on localhost/HTTPS. PDF read-aloud uses
extracted text; scanned documents need OCR, which is not included.

## Run without installing dependencies

Portable bundles include the frontend, backend, and Python runtime. Ollama is
optional and installed separately.

macOS or Linux:

```sh
curl -fsSL https://github.com/majiccode/indigoQ/releases/latest/download/install.sh | sh
~/.local/bin/indigoq
```

Windows PowerShell:

```powershell
irm https://github.com/majiccode/indigoQ/releases/latest/download/install.ps1 | iex
indigoq
```

Then open <http://127.0.0.1:8787>. Keep the terminal running while using indigoQ;
press `Ctrl+C` to stop. See the attached `INSTALL.md` for manual downloads,
data locations, and Ollama setup. `SHA256SUMS.txt` contains asset checksums.

All four platform packages passed build checks and frozen-server smoke tests:
macOS Apple Silicon, macOS Intel, Linux x64, and Windows x64.
